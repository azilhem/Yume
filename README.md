# YUME

## Présentation

**YUME** est un projet réalisé dans le cadre de la **Licence 3 Informatique MIAGE**.

Le sujet de l’exposé était libre. Notre groupe a choisi d’explorer le thème :

**« Les rêves à la lumière de l’informatique : entre neurosciences et intelligence artificielle »**

Ce travail avait pour objectif d’étudier le phénomène des rêves en croisant deux domaines scientifiques : les neurosciences et l’intelligence artificielle.

Le projet comprenait :

* la rédaction d’un **rapport en LaTeX**
* la création d’un **diaporama en LaTeX**
* une **présentation orale devant l’amphithéâtre**

L’ensemble du travail collaboratif et des rendus a été géré avec **Git** sur **Codeberg**.

**Note obtenue : 17.667 / 20**

---

## Sujet de l'exposé

Ce projet explore les liens entre le fonctionnement du cerveau pendant le sommeil et les approches informatiques modernes.

Nous abordons notamment :

* le rôle du cerveau dans la formation des rêves
* les apports des neurosciences dans la compréhension du sommeil
* les liens possibles entre intelligence artificielle et processus cognitifs
* les limites actuelles des technologies pour analyser ou modéliser les rêves
